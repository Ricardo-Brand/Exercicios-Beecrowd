
# 🐝 Exercícios Beecrowd

Repositório com soluções para exercícios da Beecrowd (URI Online Judge) em C, com foco em lógica de programação, estrutura de controle, laços, funções e manipulação de entrada/saída.

##

## 📌 Sobre o Projeto

Este repositório reúne uma coleção de soluções de problemas da plataforma Beecrowd, organizadas em C como forma de prática intensiva de lógica de programação e consolidação de conceitos fundamentais de desenvolvimento.

O principal objetivo é exercitar lógica, estruturas de repetição e resolução de desafios computacionais.

##

## 🧠 Tecnologias Utilizadas

🧠 Linguagem C

🖥️ Manipulação de entrada e saída

🔁 Estruturas de controle (if, switch)

🔄 Laços (for, while)

🧩 Funções e modularização

##

## 🧠 O que você encontra aqui

Este repositório contém soluções para diversos problemas clássicos, como:

✔ Entrada e saída básica

✔ Condicionais

✔ Estruturas de repetição

✔ Funções

✔ Desafios de lógica intermediária

Cada arquivo foi pensado para praticar um conceito específico da linguagem C, e para resolver um determinado exercício do Beecrowd.

##

## 🎓 O que Aprendi com este Projeto

Como responder a problemas online com restrições de tempo e entrada/saída

Fortalecimento da lógica de programação

Domínio de comandos de compilação C

Estruturação de código claro e modular
